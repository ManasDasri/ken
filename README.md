# ken

My portfolio: Home, Work, What I do, About, Open source and Contact, each its own page. React on Vite, one React root per page; light and dark themes.

```sh
npm install
npm run dev      # http://localhost:5173 (or the port Vite prints)
npm run build    # static site in dist/
```
